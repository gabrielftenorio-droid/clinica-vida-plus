# Clínica Vida+

A Clínica Vida+ é um projeto que comecei em 2025 durante a graduação em Análise e Desenvolvimento de Sistemas.

Na época, a proposta fazia parte de um Projeto Integrado da faculdade e consistia em pensar uma solução para informatizar alguns processos de uma clínica, como cadastro de pacientes e médicos, agendamentos e organização dos atendimentos.

A parte prática em Python que desenvolvi naquele momento era mais simples: um sistema executado pelo terminal para cadastrar e consultar pacientes e gerar algumas estatísticas.

Agora estou retomando esse projeto para desenvolver uma nova versão e aplicar, aos poucos, os conhecimentos que estou adquirindo em programação e desenvolvimento back-end.

## De onde o projeto começou

A primeira versão foi desenvolvida em Python e utilizava apenas listas e dicionários para manter os pacientes cadastrados enquanto o programa estava em execução.

O sistema permitia:

- cadastrar pacientes;
- buscar pacientes pelo nome;
- listar os pacientes cadastrados;
- calcular a idade média;
- identificar o paciente mais novo e o mais velho;
- tratar algumas entradas inválidas.

Essa versão pode ser encontrada na pasta:

```text
versao-academica-2025/
```

Ela foi mantida no repositório para registrar o ponto de partida do projeto e permitir acompanhar sua evolução.

## O que pretendo desenvolver

A ideia agora é evoluir o sistema por etapas, em vez de tentar construir tudo de uma vez.

Algumas das próximas etapas que pretendo trabalhar são:

- melhorar a organização do código;
- separar responsabilidades;
- trabalhar com orientação a objetos;
- armazenar os dados em banco de dados;
- ampliar o cadastro de pacientes;
- implementar cadastro de médicos;
- criar o agendamento de consultas;
- validar disponibilidade e conflitos de horários;
- desenvolver uma API para o sistema;
- adicionar testes.

Outras melhorias poderão ser incluídas conforme o projeto avançar e novos conhecimentos forem aplicados.
